# README media

`nara.png`, `mochi.png`, `pando.png`, and `lumi.png` are transparent native RealityKit renders of the distributed characters. `home-*.png` and `picker-*.png` are native SwiftUI panel snapshots from this source version, in English and both color schemes.

`hero.png` is a 1200 × 680 composition of the four native renders. Its editable layout is `hero.source.html`. No external fonts or images are required. Render that page at its exact dimensions to reproduce the cover.

The artwork in these images uses the repository's separate asset license. HTML/CSS source and document text use MIT.
