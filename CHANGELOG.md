# Changelog

## 0.1.0 — 2026-09-06

First standalone source release of UselessPet.

- Four animated desktop companions: Nara, Mochi, Pando, and Lumi.
- Five voluntary petting reactions, cursor following, and adjustable size.
- Menu bar home, companion picker, light/dark mode, and five languages.
- Persistent local selection and authenticated local communication.
- Source installation with uv, Xcode, and Make.
- MIT code and a separate character asset license.
